# venus-protocol (driver side)

The `vn_protocol_driver_*.h` headers are generated by [venus-protocol](https://gitlab.freedesktop.org/virgl/venus-protocol) v1.1.3 (the version Mesa
pins in `subprojects/venus-protocol.wrap`) from its `vk.xml`, `VK_EXT_command_serialization.xml` and `VK_MESA_venus_protocol.xml`. They encode every
Vulkan command into the Venus wire format that virglrenderer's `vkr` (the host side of QEMU's `virtio-gpu-gl,venus=on`) decodes, and decode its replies.

Regenerate with `scripts/gen-venus-protocol.sh <venus-protocol checkout>`, which also makes the includes freestanding (no C library headers; the
driver defines `assert`, `malloc`, `free`, `strlen` and `strcmp` for them in `src/Vulkan/vk_venus.inc`). Do not edit the generated files by hand.

`vn_cs.h` and `vn_ring.h` are this project's (the encoder, decoder and ring interface the generated code expects); see `docs/Venus.md`.
